# Chat 运行看板使用文档

## 1. 文档目的

Chat 运行看板用于集中查看 StockAgent 中所有 Chat 任务的数量、执行状态、进度和异常信息，帮助运营人员快速发现正在运行、等待处理或需要人工介入的任务。

线上访问地址：<https://stockflow-chat-board.carrollee646.chatgpt.site>

当前发布版本使用内置演示数据，主要用于界面评审和交互验证，尚未接入真实 Chat 服务。

## 2. 页面结构

### 2.1 左侧导航

当前导航包含以下入口：

- **Chat 看板**：当前页面，查看全部 Chat 的状态。
- **运行记录**：预留入口，用于后续查看历史执行记录。
- **Agent 团队**：预留入口，用于后续查看 Agent 配置和运行情况。
- **策略中心**：预留入口，用于后续管理策略版本。
- **报告归档**：预留入口，用于后续查看历史报告。

除“Chat 看板”外，其余入口在当前原型中仅用于展示信息架构。

### 2.2 顶部概览

页面顶部显示以下关键指标：

- **全部 Chat**：当前数据集中 Chat 的总数。
- **进行中**：正在被 Agent 执行的 Chat 数量。
- **需关注**：出现异常、等待输入或需要人工介入的 Chat 数量。
- **已完成**：已执行完成的 Chat 数量。
- **24h 成功率**：最近 24 小时任务成功率的演示指标。

状态数量会随着卡片拖动立即重新计算。

## 3. Chat 状态说明

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 待处理 | Chat 尚未启动，或正在等待资源 | 检查任务优先级和可用 Agent |
| 进行中 | Agent 正在执行任务 | 关注进度和运行时间 |
| 需关注 | 任务等待输入、数据异常或重试中 | 打开详情，处理警告信息 |
| 已完成 | 任务已完成 | 查看结果或进入完整对话 |

## 4. 常用操作

### 4.1 搜索 Chat

在看板上方的搜索框输入以下任一内容：

- Chat 名称，例如“收盘复盘”；
- Chat 编号，例如 `CH-1042`；
- Chat 摘要中的关键词。

搜索结果会即时更新，右侧显示当前结果数量和全部 Chat 数量。

### 4.2 按 Agent 筛选

使用搜索框右侧的 Agent 下拉列表，可以只查看指定 Agent 的任务。选择“全部 Agent”可恢复完整列表。

搜索条件和 Agent 筛选条件会同时生效。

### 4.3 查看 Chat 详情

点击任意 Chat 卡片，会从页面右侧打开详情面板。详情包括：

- Chat 编号、名称和摘要；
- 当前状态；
- 执行 Agent 和模型；
- 已用时间和最后更新时间；
- 异常或等待原因；
- 最近活动时间线。

点击面板右上角关闭按钮，或点击面板外的遮罩区域，可以关闭详情。

使用键盘时，先通过 `Tab` 聚焦卡片，再按 `Enter` 也可打开详情。

### 4.4 修改 Chat 状态

使用鼠标拖动 Chat 卡片，将其放入目标状态列。卡片状态、各列数量和顶部统计会立即更新。

当前版本的拖动结果仅保存在浏览器页面内存中。刷新页面后会恢复为演示数据，不会写入服务器。

### 4.5 识别异常任务

“需关注”列中的异常卡片具有橙色边框和警告提示。建议优先处理以下情况：

- 数据源超时或重试次数接近上限；
- 多个数据源结果冲突；
- 任务等待人工确认；
- 运行时间明显超过正常范围。

## 5. 移动端使用

页面支持窄屏和移动设备：

- 左侧导航会折叠为图标栏；
- 顶部指标改为两列排列；
- Kanban 状态列可横向滚动；
- Chat 详情面板会适配屏幕宽度。

移动端当前不建议使用拖拽修改状态；后续可增加卡片菜单作为触屏替代操作。

## 6. 当前限制

- 使用内置演示数据，未连接真实 Chat API。
- 页面刷新后，拖动产生的状态变化会丢失。
- “新建 Chat”“更多筛选”和侧边栏预留入口尚未接入业务逻辑。
- 进度、成功率和同步时间为演示信息，并非实时监控数据。
- 当前没有登录、角色权限和操作审计能力。

## 7. 推荐的生产使用流程

1. 打开看板，确认全部 Chat 数量和“需关注”数量。
2. 优先检查“需关注”列中的警告。
3. 使用 Agent 筛选定位具体执行单元的问题。
4. 打开卡片详情确认运行时间、重试和最近活动。
5. 处理异常后，由后端状态同步自动移动卡片。
6. 对已完成任务进入完整对话或结果报告进行复核。

## 8. 问题反馈建议

提交问题时建议包含：

- Chat 编号；
- 当前状态和预期状态；
- 页面显示的警告文本；
- 最后更新时间；
- 浏览器和设备类型；
- 如可提供，附上页面截图和复现步骤。
